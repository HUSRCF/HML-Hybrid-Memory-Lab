# 推理前的解释规则

以下规则在本轮新任务推理前写入，协议本身保持冻结。

1. 同时报告全部五配置、八条件、三个深度，以及当前、历史和无关事实。改善当前答案不能抵消保护事实的退化。
2. 比较单门与原始条件，再比较双门与单门；完整读取和Oracle读取分别报告。若只在Oracle下有效，结论必须保留该条件。
3. 若只关闭衰减有效，支持“该干预对全局遗忘敏感”的描述；若只关闭beta有效，支持“该干预对Delta修正敏感”的描述。二者均不直接证明自然运行发生了事实损坏，也不单独定位某个层或某条自然记忆。
4. beta关闭同时去掉Key方向擦除与新信息插入；仍不能区分这两项。衰减关闭时Delta仍可覆盖旧信息，不等于完整状态保护。
5. 双门条件优于单门只说明当前受控配置的组合效应；不同配置可能有相反变化。Shared此前48→47的退化和所有新退化必须保留。
6. 6720次新读出与6720次历史参考保持明确来源。240项端点重放验证运行一致性，不计入正式新样本量；两次smoke、缓存检查也不增加科学重复数。
7. 五种损失交互只作描述；源事件流只有八条，48变体、336问题和432绑定不是独立重复。不从最优条件选择新成功阈值。
8. 本轮掩码由未来问题的真实支持记录决定；没有检验相同更新预算下语义选择是否优于随机或位置选择。不能据此触发训练、扩模或宣称学会语义控制。
