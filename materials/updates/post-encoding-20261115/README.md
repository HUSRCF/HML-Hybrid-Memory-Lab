本轮按固定数据和源代码闭包登记，保留此前197份测量源码，新增9份共206份。完整前缀/尾部/问题的分块位置固定，不要求与单次整段prefill数值完全等同，也不根据任务结果调整容差。全量报告前后答案、退化、角色、文体、长度及事件流，不剔除编码后就答错的样本。

这是冻结模型的机制诊断。没有新架构成功门槛、显著性声明或训练/扩模触发条件。尾部门控仍会影响后续Query、隐藏表示、卷积和尾部KV；旧KV相同不等于唯一定位到状态矩阵存储。仅比较接尾部前后还会混入距离/位置变化，主要因果对照使用相同尾部Token和位置。

缓存保护会主动拒绝声明的48项以外出现的张量属性，检查源张量内容、实际元数据、布局、存储隔离与输出logits。测试包含逐项破坏48个缓存张量、修改元数据、构造共享存储视图、篡改旧KV、漏掉Attention层或引入概率泄漏。首次完整套件257项通过；增加额外张量检查后的17项专项测试通过，最终完整套件另行保存。
