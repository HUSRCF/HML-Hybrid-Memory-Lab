## 干预与全部层结果

N 为正常前缀及尾部。H 从正常尾部后缓存独立分叉，只恢复全部 18 个递归矩阵为正常前缀的矩阵，保留正常卷积、历史 KV 和尾部后位置；没有在尾部关闭写入。HN 向 H 接收方换入 N 的问题 Query，NH 为反向干预。

每次新读出只在一个选定 Attention 层的已知问题后缀 forward 中复制实际 post-q_norm/post-RoPE Query。其余五层使用当次计算的原生 Query 对象，后续 GDN、Query、问题 Token 的 KV 和答案可以自然变化；不把后续计算夹持成参考运行。后续 gold 评分和自由生成不再替换 Query。源缓存及包装器接收到的非 Query 参数都受到实际张量保护。

GDN 适配器只换索引 15 的 Query，即将 H 接收方新值从 2/32 恢复到 32/32，总体从 162/192 变成 191/192。相对 HH 有 30 次增益、1 次退化；全部增益为新值，退化是无关尾部后的当前目标值。其全部 192 项自由生成与六层 HN 参考相同，但所有 NLL 都不同，不能称为整个计算或隐藏表示相同。

索引 19 的 HN 为 188/192，新值 28/32，固定前缀 160/160，对 HH 有 26 次增益、0 次退化。索引 15 新值更多，却损失一项固定前缀答案。全部历史/保护角色与其他层结果均保留，不能只以单个最高准确率定义最优架构。

反向行为并不对称：GDN 的 NH.L15 新值 26/32，NH.L19 为 21/32，历史六层 NH 为 3/32。其 32 个新值问题中，有 15 项在每一个单层反向干预时都答对，却在六层参考干预下答错。该描述不证明某种高阶协同、六层必要性或可加性，也可能涉及后续原生计算的补偿；没有测量任意双层或多层组合。

GDN 的 NH.L11 总体 192/192，是在这批复用输入上的条件干预结果；它需要参考供体前向，不是已训练或可部署的新方法，也不能据此主张超过正常强基线。正常 GDN NN 仍为 191/192。

原生模型没有同样集中的单层效果：HN.L11、L15、L19 新值为 20、19、23/32，六层参考为 26/32；各层也有固定前缀损害。原生 HN.L19 对 HH 为 12 次增益、4 次退化，HN.L15 为 9 次增益、4 次退化。原生有一项新值只在六层组合参考下修复，六个单层都未修复；这也不证明六层都必要。

现有 GDN 适配器本来位于第 4 个四层组的更新路径，涉及 12、13、14 层，索引 15 正在其后。这里定位的是这一个固定检查点的干预行为，不推断全部混合模型都按相同层角色工作。供体 Query 含上游递归与 Attention 计算，可能包含答案相关信息，效果不唯一证明语义地址机制。
